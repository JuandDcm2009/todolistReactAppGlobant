# TodoList App 📋✏️
Simple TodoList project. You can Add tasks, Remove tasks, Mark as checked a Task and see your completed tasks.

## Technologies
- React + Vite 
- JavaScript
- HTML & CSS

## Deployment
1. Clone the repository
2. Excute `npm run dev` at the terminal
